# clrmamepro

Tool for scanning and rebuilding ROM sets against DAT files (especially MAME).

## Download
Official site: https://mamedev.emulab.it/clrmamepro/

Latest classic clrmamepro (4.050):
- 64-bit zip: available from the official downloads page
- Newer "clrmame" (0.6.x / 0.7.x) is also available from the same site

## Place the tool here
Extract the zip into this folder so that `cmpro64.exe` (or equivalent) is present.

## Usage with your MAME DAT
1. Run clrmamepro
2. Create a new profile and load the MAME DAT from `data/MAME/`
3. Point the ROM path at your collection (e.g. `H:\Games\Emulators\tmp\mame\roms`)
4. Run a scan to verify sets like `10yard.zip`
