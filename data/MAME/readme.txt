The folders contained in this package contain:

- DATs: Dats created with ClrMAME Pro:

  * ARCADE 0.289.dat           : This is for "Arcade" a frontend derived from MAME only emulates the working arcade games present in MAME; you can download it here: https://arcade.mameworld.info/
  * HBMAME 0.289.1 (split).dat : This is only the frontend HBMAME that emulates only hacked version of games; you can download it here: https://hbmame.1emulation.com/
  * MAME 0.289 (arcade).dat    : This is the only version with arcade systems.
  * MAME 0.289 (mess).dat      : This is the only version with homemade systems (PC, console, etc.); before it was known as "MESS"; you can download it here: https://www.progettosnaps.net/mess/
  * MAME 0.289.dat             : This is for the MAME in the complete version; you can download it here: https://mamedev.org/release.html
  * MAMEUI 0.289.dat           : This is for the MAME in the complete version; you can download it here: https://messui.1emulation.com/
  * MAME_BIOS_289.dat - MAME_CHD_289.dat - MAME_Devices_289.dat - MAME_ROMs_289.dat - MAME_Samples_289.dat

- DOCs: The original whatsnew.txt file (only for the stable version) and the list of all the emulated games with my unique mameUD.
- XML: The xml file generated directly by MAME's original executable, with the -listxml command (available only for MAME).
       Since version 0.270, the file that includes all list software in "\hash", including those not yet supported, is also in this folder.
